- **[jdbc-v2]** Added the `SEGMENTS` and `SHARDS` keywords from ClickHouse 26.11 to the driver's keyword list, so the
  keyword check passes against ClickHouse 26.11. The `ANTLR4` and `ANTLR4_PARAMS_PARSER` parsers now accept `shards`
  as an identifier or alias, for example `SELECT 1 AS shards` or `INSERT INTO shards VALUES (?)`. Before, these parsers
  marked such a statement as unparsed: `execute()` took the query path instead of returning an update count, and an
  insert into a table named `shards` did not use the RowBinary writer (`beta.row_binary_for_simple_insert`). The
  default `JAVACC` parser and the word `segments` were not affected. (https://github.com/ClickHouse/clickhouse-java/issues/3428)
