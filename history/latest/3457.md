## Bug Fixes

- **[jdbc-v2]** With the `ANTLR4` and `ANTLR4_PARAMS_PARSER` SQL parser backends, 64 keywords that the lexer
  knows but the grammar did not accept as identifiers (for example `CLIENT`, `SCHEMA`, `MODEL`, `CONDITION`,
  `PAGE`, `CONFIG`) can now be used as unquoted column and table names. Before, an `INSERT` with such a column
  failed to parse, its `VALUES` list was discarded, and `PreparedStatement#executeBatch()` silently sent one
  `INSERT` per row instead of a single multi-row `INSERT`. The default `JAVACC` backend was not affected.
  (https://github.com/ClickHouse/clickhouse-java/issues/3457)
