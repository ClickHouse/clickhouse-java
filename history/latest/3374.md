- **[client-v2]** Fixed an insert of a Java `enum` constant with a class body into a `Dynamic` column. The insert
  failed on the client with `NullPointerException: Cannot read the array length because "constants" is null`. The
  class of such a constant is an anonymous subclass of the enum class and has no enum constants of its own, but
  `ClickHouseEnum.of(Class)` read the constants from that class. Now `ClickHouseEnum.of(Class)` reads them from the
  enum class, so the value gets the same type in the `Dynamic` column as the other constants of the enum.
  `ClickHouseEnumValue.of(Enum)` failed the same way for such a constant and works now too.
  (https://github.com/ClickHouse/clickhouse-java/issues/3374)
