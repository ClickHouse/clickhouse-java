- **[jdbc-v2]** Added the `RANGES` keyword (part of the new `TIME RANGES` keyword) and the `Obfuscate` table engine
  from ClickHouse 26.11 (HEAD) to the driver's keyword and engine lists, so the keyword and table-engine checks pass
  against ClickHouse HEAD. There is no behavior change: both SQL parsers already accept `RANGES` as an alias, and
  `DatabaseMetaData#getTables` already reports an unmapped engine as `TABLE`, which is the type that `Obfuscate` now
  maps to. (https://github.com/ClickHouse/clickhouse-java/issues/3222)
