- **[client-v2]** Fixed an insert of a Java `enum` value as a key or a value of a `Map` in a `Dynamic` column. The
  insert failed on the server with `DataTypeEnum enumeration cannot be empty`. The client builds the `Map` type again
  from the type names of its key and value, and the type name of an `enum` was always `Enum16` without the elements.
  Now the type name has the elements and the same width that the client writes for a top-level `enum` value, for
  example `Map(String, Enum8('A' = 0, 'B' = 1, 'C' = 2))`. A `Map` that holds such a `Map` as its value is fixed too.
  (https://github.com/ClickHouse/clickhouse-java/issues/3346)
