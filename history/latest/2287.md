- **[client-v2, jdbc-v2]** Fixed a server error with an exception type other than `DB::Exception` (for example
  `Code: 519. DB::NetException: ...` or `Code: 999. Coordination::Exception: ...`) reported as
  `<Unreadable error message>`. The client looked for the text `<code>. DB::Exception:` in the response body to find
  the start of the message. It now looks for `<code>. `, which does not depend on the exception type.
  (https://github.com/ClickHouse/clickhouse-java/issues/2287)
