- **[client-v2, jdbc-v2]** The `User-Agent` header now has the CPU architecture that the JVM reports (`os.arch`) as
  the `arch` entry, after `os`: `(lv:java/17.0.2; os:Linux; arch:amd64; hc:ahc_5.6.4)`. Client metadata can set
  `arch` to replace the value of the client.
  (https://github.com/ClickHouse/clickhouse-java/issues/2458)
