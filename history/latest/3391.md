- **[jdbc-v2]** The JavaCC SQL parser now accepts a heredoc (`$$...$$`, `$tag$...$tag$`) as the cluster name in
  `ON CLUSTER` and as the string of `INTERVAL '...'`. Before, such a statement could not be parsed: `ALTER TABLE ... ON
  CLUSTER $$c$$` and `UPDATE ... ON CLUSTER $$c$$` were reported as statements with a result set
  (`Statement.execute()` returned `true`), and a batch of `INSERT ... VALUES (?, now() - INTERVAL $$1 day$$)` was sent
  as one request per row. (https://github.com/ClickHouse/clickhouse-java/issues/3391)
