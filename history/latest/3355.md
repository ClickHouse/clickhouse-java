- **[jdbc-v2]** Fixed `DatabaseMetaData#getPrimaryKeys` on ClickHouse 26.8 and later, which returned `(id)` as the
  `COLUMN_NAME` of a table with `ORDER BY (id)`. Since 26.8 the server keeps the parentheses around a key column in
  `system.tables.primary_key`. The driver now removes parentheses that hold a whole key column, so all server
  versions give `id`. The parentheses of a tuple such as `(a, b)` and of an expression such as `(a + b) * (c + d)`
  stay. The driver also no longer splits a key column at a comma inside parentheses. `ORDER BY (cityHash64(a, b), id)`
  now gives the rows `cityHash64(a, b)` and `id` with `KEY_SEQ` 1 and 2. Before, all server versions gave the three
  rows `cityHash64(a`, `b)` and `id`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3355)
