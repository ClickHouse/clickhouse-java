- **[jdbc-v2]** With `beta.row_binary_for_simple_insert=true`, an `INSERT` prepared after `Connection.setSchema(db)`
  now writes to `db`. Before, the RowBinary writer sent the rows to the database from the connection configuration:
  they landed in the wrong table when a table with the same name existed there, or failed with `UNKNOWN_TABLE`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3212)
