- **[repo]** Fixed duplicate classes on the classpath of an application that uses `com.clickhouse:clickhouse-jdbc-all`.
  The jar of this artifact contains all its dependencies, but its POM also declared them, so Maven added
  `clickhouse-jdbc` (classifier `all`), `jdbc-v2`, `client-v2`, `clickhouse-data` and the third-party jars next to it.
  The POM now declares no dependencies, so tools that read the POM no longer list the bundled libraries. The JDBC docs
  now show how to use the `all` classifier of `clickhouse-jdbc` without the dependencies of the standard artifact.
  (https://github.com/ClickHouse/clickhouse-java/issues/2474)
