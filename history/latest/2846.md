- **[client-v2]** Reverted [#2920](https://github.com/ClickHouse/clickhouse-java/pull/2920). A non-empty
  `Array(Nullable(T))` read from the binary format is `Object[]` again (`Array(Nullable(Float64))` is
  `Object[]`, not `Double[]`). Variant, Dynamic, and Geometry arrays stay `Object[]`. An empty array
  takes its component type from `ClickHouseDataType.getPrimitiveClass()` and does not read an element,
  so that class can differ from a non-empty array of the same column. Elements of a nullable array are
  read on the nested-value path, so a string inside `Array(Nullable(String))` stays a `String` when
  binary string support is enabled.
  (https://github.com/ClickHouse/clickhouse-java/issues/2846)
