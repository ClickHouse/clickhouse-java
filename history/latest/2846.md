- **[client-v2]** Reverted [#2920](https://github.com/ClickHouse/clickhouse-java/pull/2920). A non-empty
  `Array(Nullable(T))` read from the binary format is `Object[]` again (`Array(Nullable(Float64))` is
  `Object[]`, not `Double[]`). Variant, Dynamic, and Geometry arrays stay `Object[]`, including when
  empty. An empty non-nullable array again takes its component type from
  `ClickHouseDataType.getPrimitiveClass()`. Elements of a nullable array are
  read on the nested-value path again, so a string inside `Array(Nullable(String))` stays a `String` when
  binary string support is enabled.
  (https://github.com/ClickHouse/clickhouse-java/issues/2846)
