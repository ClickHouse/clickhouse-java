- **[jdbc-v2]** `Connection.createArrayOf(typeName, ...)` and `Connection.createStruct(typeName, ...)` now throw
  `SQLException` (SQLState `HY000`) when the driver cannot parse `typeName`, for example an unknown type, unbalanced
  parentheses, invalid type parameters, or an empty string. Before, these methods threw an unchecked
  `IllegalArgumentException` or `NumberFormatException`, so a `catch (SQLException e)` block and frameworks that
  translate `SQLException` did not get the error. The parser exception is the cause of the `SQLException`, and the
  message contains the type name. (https://github.com/ClickHouse/clickhouse-java/issues/3347)
