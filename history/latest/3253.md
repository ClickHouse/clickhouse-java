- **[client-v2]** Fixed a memory leak where every new pooled HTTP connection added one entry to an internal queue of
  connection times that was only drained by the metrics gauge. Without a metrics registry the queue was never emptied
  and grew for the lifetime of the client. Connection times are now recorded only when metrics are enabled. `jdbc-v2`
  is affected as well because it uses `client-v2`. (https://github.com/ClickHouse/clickhouse-java/issues/3253)
