- **[client-v2, jdbc-v2]** Fixed type names with an Enum label that ends with a backslash, such as
  `Enum8('a\\' = 1, 'z' = 2)`. The type parser treated the closing quote as escaped because the character before it
  was a backslash, so it failed with `NumberFormatException`. A query that returned such a column failed before the
  first row, and so did a `TableSchema` built from the type name. The parser now skips the character after each
  backslash in a quoted string, so `\\` is one escaped backslash and the next quote closes the string. Escaped quotes
  such as `\'` are read as before. (https://github.com/ClickHouse/clickhouse-java/issues/3371)
