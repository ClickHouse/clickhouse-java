- **[client-v2, jdbc-v2]** Fixed Enum type names with a repeated value or name, such as `Enum8('a' = 1, 'b' = 1)` or
  `Enum8('a' = 1, 'a' = 2)`, in a type name that the application writes. The client accepted them, so both labels
  were written with the same value and the second one read back as the first. The server rejects these types. Now
  the client rejects them too with an `IllegalArgumentException` that names both entries. The same check applies to
  `new ClickHouseEnum(String[], int[])`. Type names from the server never repeat a value or name and are read as
  before. (https://github.com/ClickHouse/clickhouse-java/issues/3349)
