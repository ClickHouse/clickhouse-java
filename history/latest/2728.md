- **[client-v2, jdbc-v2]** Fixed `getString()` on array values (`Array`, `QBit`, and arrays in `Variant` or `Dynamic`)
  when readers, `GenericRecord` or `ResultSet` objects in different threads convert them at the same time. All of them
  share one `DataTypeConverter`, and its array writers kept the current column and output buffer in fields. Parallel
  conversions changed each other's state: a result had wrong quotes or values from another thread, or the call failed
  with a `NullPointerException`. The writers now get the column and the buffer as method parameters, so
  `DataTypeConverter` keeps no conversion state and is thread-safe.
  (https://github.com/ClickHouse/clickhouse-java/issues/2728)
