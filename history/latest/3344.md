- **[client-v2, jdbc-v2]** Fixed Enum type names that leave out the values, such as `Enum8('a', 'b')` or
  `Enum8('a' = 5, 'b')`, in a type name that the application writes. This covers a `TableSchema` for
  `Client#newBinaryFormatReader(response, schema)`, `RowBinaryFormatWriter`, `Client#register(Class, schema)`,
  `Connection#createArrayOf` and `Connection#createStruct`. They failed with `Invalid enum entry`, and a quoted name
  that contains `=` failed with `NumberFormatException`. Now the client numbers these entries the same way as the
  server. An entry without a value gets the value of the first entry plus its position, and counting starts at 1 when
  the first entry has no value. A list where only some of the entries after the first one have a value is rejected,
  as on the server. Type names from the server always have explicit values and are read as before.
  (https://github.com/ClickHouse/clickhouse-java/issues/3344)
