- **[jdbc-v2]** Fixed `ResultSetMetaData#getColumnClassName` for `IPv4` and `IPv6` columns, which returned
  `java.lang.Object`. Now `IPv4` reports `java.net.Inet4Address` and `IPv6` reports `java.net.InetAddress`, the
  classes of the values that `ResultSet#getObject` returns. `IPv6` reports `InetAddress` (not `Inet6Address`) because
  an IPv4-mapped value (`::ffff:a.b.c.d`) is returned as an `Inet4Address`. `getColumnType` stays `Types.OTHER`, and
  `ResultSet#getObject` returns the same values as before. Array elements use the same classes: the `VALUE` column of
  `java.sql.Array#getResultSet()` reports the same class name, and `java.sql.Array#getArray()` now returns an
  `Inet4Address[]` / `InetAddress[]` instead of an `Object[]`. `getObject(int, Class)` on the result set of a
  `java.sql.Array` now also accepts a superclass or an interface of the element value (for example,
  `InetAddress.class`). (https://github.com/ClickHouse/clickhouse-java/issues/3189)
