- **[client-v2, jdbc-v2]** Fixed the type name of a `Nullable(Tuple(...))` column. The name was one closing
  parenthesis short, for example `Nullable(Tuple(Int32, String)`, at the top level and inside `Array`, `Map`, `Tuple`,
  `Nested` and `JSON`. The wrong name was returned by `ResultSetMetaData#getColumnTypeName`,
  `java.sql.Array#getBaseTypeName`, `Struct#getSQLTypeName` and the columns of `Client#getTableSchema`.
  `java.sql.Array#getResultSet()` of a `Nested` column with a `Nullable(Tuple(...))` field failed with
  `IllegalArgumentException`, because it parses the name again. The type name parser now reads the closing
  parentheses of the `Nullable` and `LowCardinality` wrappers after every type with parameters, so the names of
  `Nullable(JSON(...))` and `Nullable(QBit(...))` are correct too. (https://github.com/ClickHouse/clickhouse-java/issues/3382)
