- **[client-v2, jdbc-v2]** Breaking change: the `User-Agent` header now uses the standard ClickHouse client format,
  `<client name> clickhouse-java-v2/<version> (lv:java/<java.version>; os:<os.name>; hc:ahc_<version>)`:
  `jvm:<version>` is now `lv:java/<version>`, the OS is the `os:` entry, and the trailing
  `Apache-HttpClient/<version>` is replaced by the `hc:ahc_<version>` entry (the Apache HttpClient version that the
  client is built with). Added `Client.Builder#setClientName(String, Map)` (property `client_id_metadata`) to add
  key/value pairs to the comment group. The pairs can set `lv`, `os` and `hc` to replace the values of the client.
  Leading and trailing whitespace is removed from the client name and from a custom `User-Agent` value. A blank value
  set for one operation counts as not set. The client logs a warning if the `User-Agent` value of the client
  configuration is longer than 200 characters.
  Queries that parse `http_user_agent` in `system.query_log` must use the new format.
  (https://github.com/ClickHouse/clickhouse-java/issues/3202)
