- **[client-v2, jdbc-v2]** Breaking change: the `User-Agent` header now uses the standard ClickHouse client format,
  `<client name> clickhouse-java-v2/<version> (lv:java/<java.version>; os:<os.name>)`: `jvm:<version>` is now
  `lv:java/<version>`, the OS is the `os:` entry, and the trailing `Apache-HttpClient/<version>` is removed. Added
  `Client.Builder#setClientName(String, Map)` (property `client_metadata`) to add key/value pairs to the comment group.
  Queries that parse `http_user_agent` in `system.query_log` must use the new format.
  (https://github.com/ClickHouse/clickhouse-java/issues/3202)
