- **[client-v2]** `JSONEachRowFormatReader` now throws a `ServerException` when the server reports a failure after the response started. With `http_write_exception_in_output_format` (default on) the server appends a row `{"exception": "Code: ..."}` and ends the response normally; the reader returned it as an ordinary all-null data row, so the failure was silent. The rows read before the error are still returned, and the exception surfaces on the next `next()` call with the server error code. A query that selects only an `exception` column is not affected.
  (https://github.com/ClickHouse/clickhouse-java/issues/3220)
