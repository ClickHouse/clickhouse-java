- **[jdbc-v2]** A `LocalDateTime` bound via `setObject` on the text path is now interpreted in the
  server/column time zone instead of the JVM default time zone, matching `Timestamp` and the reader.
  Behaviour change on a non-UTC JVM; set `jdbc_legacy_localdatetime_jvm_timezone=true` to restore the
  old behaviour. (https://github.com/ClickHouse/clickhouse-java/issues/3127)
