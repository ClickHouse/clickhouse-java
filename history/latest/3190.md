- **[jdbc-v2]** Breaking change: `java.sql.Array#getBaseType()`/`getBaseTypeName()` of a multi-dimensional array
  now report the element type, which is the next array level (`ARRAY`/`Array(UInt8)` for `Array(Array(UInt8))`).
  Before, they reported the innermost type (`SMALLINT`/`UInt8`), which did not match the element values. This also
  applies to arrays from `Connection#createArrayOf`. The new driver property
  `jdbc_multi_dimensional_array_element_type` (default `true`) controls this behavior. Set it to `false` to get the
  innermost type, as in earlier versions. (https://github.com/ClickHouse/clickhouse-java/issues/3190)
