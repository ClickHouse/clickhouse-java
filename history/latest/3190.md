- **[jdbc-v2]** Fixed `java.sql.Array#getBaseType()`/`getBaseTypeName()` of a multi-dimensional array, which reported
  the innermost type (e.g. `SMALLINT`/`UInt8` for `Array(Array(UInt8))`). They now report the element type, which is
  the next array level (`ARRAY`/`Array(UInt8)`). This also applies to arrays from `Connection#createArrayOf`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3190)
