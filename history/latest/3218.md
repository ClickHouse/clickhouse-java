- **[jdbc-v2]** The documented driver property `disable_frameworks_detection` is now a driver property and is no
  longer forwarded to the client, so setting it no longer fails the connection with
  `Unknown and unmapped config properties`. The property is now also read from the connection URL, not only from the
  `Properties` argument. The documented default is corrected to `false`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3218)
