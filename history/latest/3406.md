- **[jdbc-v2]** Fixed the RowBinary writer for simple `INSERT ... VALUES (?, ...)` statements
  (`beta.row_binary_for_simple_insert=true`). It dropped the value of `setBytes`, `setURL` and of all overloads of
  `setAsciiStream`, `setUnicodeStream`, `setBinaryStream`, `setCharacterStream` and `setNCharacterStream`. The column
  then got `NULL` or its default, or the insert failed with "An attempt to write null into not nullable column". Now
  the writer stores the value: `byte[]` and `InputStream` values byte for byte, `Reader` and `URL` values as text. The
  setter reads the stream before it returns. It fails with `SQLException` when the length is negative or the stream
  ends before the length. (https://github.com/ClickHouse/clickhouse-java/issues/3406,
  https://github.com/ClickHouse/clickhouse-java/issues/3334)
