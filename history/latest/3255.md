- **[jdbc-v2]** `Driver#getPropertyInfo` now returns a description for each client and driver property. Before, the
  description was `null`, or `(User Defined)` when the property had a value. A property that is neither a client nor a
  driver property, for example a `clickhouse_setting_*` key, keeps the description `(User Defined)`. Property names,
  values, and defaults are not changed. The new generated class `DriverPropertiesDescriptions` returns the descriptions
  of the `DriverProperties` constants as a map.
  (https://github.com/ClickHouse/clickhouse-java/issues/3255)
- **[client-v2]** New annotation `com.clickhouse.client.api.Description`: each `ClientConfigProperties` constant has a
  short description in it. The new generated class `ClientConfigPropertiesDescriptions` returns the descriptions as a
  map. A configuration property constant without a description fails the build.
  (https://github.com/ClickHouse/clickhouse-java/issues/3255)
