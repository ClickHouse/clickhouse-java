- **[jdbc-v2]** `Driver#getPropertyInfo` now returns a description for each client and driver property. Before, the
  description was `null`, or `(User Defined)` when the property had a value. The descriptions come from a resource that
  is bundled with the driver. A property that is neither a client nor a driver property keeps the description
  `(User Defined)`. Property names, values, and defaults are not changed.
  (https://github.com/ClickHouse/clickhouse-java/issues/3255)
