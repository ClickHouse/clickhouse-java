- **[client-v2, jdbc-v2]** Prevented Apache HttpClient managed connections from emitting raw wire logs when
  root logging or `org.apache.hc.client5.http.wire` is set to `DEBUG`. Both pooled and basic connection managers
  now create connections that bypass Apache's raw-byte logging wrapper without changing application logging
  configuration, while normal non-wire diagnostics remain available. This prevents credentials, custom sensitive
  headers, SQL, request bodies, and response data from being exposed through raw wire output.
  (https://github.com/ClickHouse/clickhouse-java/issues/3251)
