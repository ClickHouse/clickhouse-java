- **[client-v2, jdbc-v2]** The connections of the client no longer write HTTP wire logs. Apache HttpClient wrote all
  request and response bytes, including the `Authorization` header and other credentials, SQL, and data, to the
  `org.apache.hc.client5.http.wire` logger when that logger was enabled for `DEBUG`, also when it only inherited
  `DEBUG` from the root logger. This is now disabled for pooled and non-pooled connections, whatever the logging
  configuration is, and no option turns it on. The logging configuration of the application is not changed, and
  other `DEBUG` logs are not changed: the `org.apache.hc.client5.http.headers` logger still writes request headers at
  `DEBUG` (https://github.com/ClickHouse/clickhouse-java/issues/3248).
  (https://github.com/ClickHouse/clickhouse-java/issues/3251)
