## Bug Fixes

- **[jdbc-v2]** With the `ANTLR4` and `ANTLR4_PARAMS_PARSER` SQL parser backends, the target of an `INSERT` is no
  longer replaced by a table the statement reads (a CTE name, a `FROM` or `JOIN` table, or a table in a scalar
  subquery in `VALUES`). The parsed target is used to pick the table for the RowBinary writer, so with
  `beta.row_binary_for_simple_insert=true` rows could be written into the source table instead of the target.
  The default `JAVACC` backend was not affected. (https://github.com/ClickHouse/clickhouse-java/issues/3129)
