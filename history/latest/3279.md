- **[jdbc-v2]** Fixed parsing of an `INSERT` that starts with a `WITH` clause, such as
  `WITH a AS (SELECT ...) INSERT INTO t SELECT ... FROM a`. The parsers accepted `WITH` only before `SELECT`, so the
  statement logged `Failed to parse SQL` and was run as a query: `Statement#execute()` returned `true` and
  `getUpdateCount()` returned `-1`. It is now parsed as an `INSERT`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3279)
