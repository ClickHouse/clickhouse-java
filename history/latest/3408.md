## Bug Fixes

- **[jdbc-v2]** Fixed the RowBinary writer for simple `INSERT ... VALUES (?, ...)` statements
  (`beta.row_binary_for_simple_insert=true`). The `setObject` overloads with a target SQL type
  (`setObject(int, Object, int)`, `setObject(int, Object, int, int)`, `setObject(int, Object, SQLType)` and
  `setObject(int, Object, SQLType, int)`) failed with "This form of setObject is not supported yet". Frameworks use these
  overloads, for example Spring `JdbcTemplate` with `SqlParameterValue`. Now they check the value against the target
  type the same way as the SQL path, and then store it the same way as `setObject(int, Object)`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3408)
