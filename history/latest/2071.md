- **[client-v2]** Added `Client#insertQuery` to insert data with an `INSERT` statement that the application writes,
  for example `INSERT INTO t (a, b) SELECT a, sum(b) FROM input('a String, b UInt64') GROUP BY a`. Before, the
  insert methods could only make `INSERT INTO <table> [(columns)] FORMAT <format>`. The client sends the statement
  as it is. When the format argument is not `null`, the client appends `FORMAT <format>`. When it is `null`, the
  statement must have its own `FORMAT` clause. The data can come from a `DataStreamWriter` or an `InputStream`, and
  server-side query parameters (`{name:Type}`) are supported. The operation reports no target table to metrics and
  spans. The existing `insert` methods do not change.
  (https://github.com/ClickHouse/clickhouse-java/issues/2071)
