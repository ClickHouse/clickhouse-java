- **[client-v2]** Fixed writing a value that contains itself into a `Dynamic` column. The client walks the value to
  find its type. For an array or `List` that holds itself this walk never ended, so the insert never returned. For a
  `Map` that holds itself it threw `StackOverflowError`, and later requests of the same client failed with
  `Connection pool shut down`. A cycle through more than one container, for example an array that holds a list that
  holds the array, failed in the same way. Such a value now fails at once with `ClientException` and the message
  `Cannot serialize <class> into a Dynamic column because it contains itself`. A value that holds the same array,
  list or map more than once without containing itself keeps its type, for example `Array(Array(Int32))`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3177)
