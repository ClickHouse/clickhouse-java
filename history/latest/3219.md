- **[jdbc-v2]** Keep detected frameworks in the `User-Agent` header after
  `Connection.setClientInfo("ApplicationName", ...)`. The driver now sends them as an `fw` entry in the comment group
  (`... jdbc-v2/<version> clickhouse-java-v2/<version> (fw:apache.spark; lv:...)`) instead of a second
  parenthesized group after the client name. Null and empty application names
  remove only the application prefix, without adding leading whitespace. Empty `client_name` and legacy `product_name`
  values also no longer add leading whitespace when connecting.
  (https://github.com/ClickHouse/clickhouse-java/issues/3219)
