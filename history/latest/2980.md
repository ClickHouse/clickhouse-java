## New Features

- **[client-v2]** The `Native` format reader now decodes `QBit(Int8, ...)`, strided `QBit(element_type, dimension, stride)`,
  `Nullable(QBit(...))`, `Array(QBit(...))` and `Array(Nullable(QBit(...)))` columns to the same values as the
  `RowBinary` readers. Before, it rejected these columns with a `ClientException`. A `QBit` inside a `Tuple`, `Map`,
  `Variant` or multi-level `Array` is still rejected.
  (https://github.com/ClickHouse/clickhouse-java/issues/2980)
