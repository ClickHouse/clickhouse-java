- **[jdbc-v2]** Added the `RETURNING` and `SHARED` keywords and the `Elasticsearch` table engine from ClickHouse 26.11
  (HEAD) to the driver's keyword and engine lists, so the keyword and table-engine checks pass against ClickHouse HEAD.
  `DatabaseMetaData#getTables` now reports a table with the `Elasticsearch` engine as `REMOTE TABLE` (it was reported
  as `TABLE`), like the other external-storage engines. Both SQL parsers already accept `RETURNING` and `SHARED` as
  aliases. (https://github.com/ClickHouse/clickhouse-java/issues/3265)
