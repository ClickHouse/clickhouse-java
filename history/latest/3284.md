- **[jdbc-v2]** Fixed `ResultSet#getObject(int, Class)` on the result set returned by `java.sql.Array#getResultSet()`
  failing with `Value of class java.sql.Date cannot be converted to class java.time.LocalDate` for arrays of
  `Date`/`Date32`, `DateTime`/`DateTime64` and `Time`/`Time64`. These elements can now also be read as
  `java.time.LocalDate`, `java.time.LocalDateTime` and `java.time.LocalTime`, the same as for non-array columns.
  (https://github.com/ClickHouse/clickhouse-java/issues/3284)
