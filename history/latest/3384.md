- **[client-v2, jdbc-v2]** Fixed reading a `Dynamic` value whose type has a tuple without element names, such as
  `Tuple(Int32, String)`, `Array(Tuple(Int32, String))` or `Map(String, Tuple(Int32, String))`. The reader did not
  read the element types of such a tuple, so the rest of the row was read from the wrong bytes. Depending on the data,
  the read failed with `Missing nested data type`, `Unsupported data type with tag 97` or `End of stream reached
  before reading all data`, or it returned wrong values or no rows. Now the element types are read and the value is
  returned as `Object[]`, the same as a tuple with element names. (https://github.com/ClickHouse/clickhouse-java/issues/3384)
