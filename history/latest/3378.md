- **[jdbc-v2]** Fixed `ResultSet#getArray` and `ResultSet#getObject` for an array of a geo type, for example
  `Array(Ring)`, `Array(Polygon)`, `Array(Geometry)`, `Array(Nullable(Point))` or `Array(Array(Ring))`. They threw
  `SQLException` caused by a `NullPointerException` in the constructor of `com.clickhouse.jdbc.types.Array`. The
  conversion tried to make a `java.sql.Array` of each geo element, but it had no column for the element. Now the
  elements are kept as read. `getArray()` of the result is an `Object[]` of nested Java arrays, for example a
  `double[][]` for each `Ring`, and `null` for a `NULL` element. `getBaseTypeName()` is the element type, for example
  `Ring`, and `getBaseType()` is `Types.ARRAY`. (https://github.com/ClickHouse/clickhouse-java/issues/3378)
