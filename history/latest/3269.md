- **[client-v1, client-v2, jdbc-v1, r2dbc]** Upgraded `at.yawk.lz4:lz4-java` from `1.11.4` to `1.12.1` to fix
  [GHSA-48mj-8f7c-7qfm](https://github.com/yawkat/lz4-java/security/advisories/GHSA-48mj-8f7c-7qfm). Since `1.12.0` the
  library validates LZ4 input more strictly: malformed data fails earlier with an exception, and a stream that failed
  once keeps failing. Valid data is not affected. The v1 compression docs now name `at.yawk.lz4:lz4-java:1.12.1`
  instead of the unmaintained `org.lz4:lz4-java:1.8.0`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3269)

- **[client-v1]** Upgraded the optional `com.aayushatharva.brotli4j:brotli4j` dependency and its native artifacts
  (`native-linux-x86_64` and the others) from `1.12.0` to `1.24.0`. Versions up to `1.23.0` bundle a Brotli decoder with
  an out-of-bounds write
  ([GHSA-x524-jrqf-vwq6](https://github.com/hyperxpro/Brotli4j/security/advisories/GHSA-x524-jrqf-vwq6)). brotli4j is
  not bundled: applications that add it for Brotli compression must upgrade it themselves.
  (https://github.com/ClickHouse/clickhouse-java/issues/3269)

- **[client-v2, jdbc-v2]** Upgraded `com.fasterxml.jackson.core:jackson-databind` and `jackson-core` from `2.22.0` to
  `2.22.4` to fix
  [GHSA-m8xf-2cr7-77ph](https://github.com/FasterXML/jackson-databind/security/advisories/GHSA-m8xf-2cr7-77ph) and the
  other advisories fixed in `2.22.1`-`2.22.4`. Jackson is a `provided` dependency: applications that use
  `JacksonJsonParserFactory` must upgrade their own Jackson. `jackson-annotations` stays at `2.22`, the latest 2.x
  version.
  (https://github.com/ClickHouse/clickhouse-java/issues/3269)

- **[client-v2]** Upgraded `org.ow2.asm:asm` from `9.7` to `9.11.1`.
  (https://github.com/ClickHouse/clickhouse-java/issues/3269)

- **[examples]** Upgraded Jackson in `examples/client-v2` (from `2.18.11`) and in the JSON processor examples (from
  `2.22.3`) to `2.22.4`. (https://github.com/ClickHouse/clickhouse-java/issues/3269)
