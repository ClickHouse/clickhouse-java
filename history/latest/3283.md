- **[client-v2]** Fixed reading `Array(Nullable(T))` columns whose element values are read as a different class than
  the one declared for `T`. Reading failed with `IllegalArgumentException: array element type mismatch` for
  `Array(Nullable(UInt64))` (values are `BigInteger`, the array was `UnsignedLong[]`), for
  `Array(Nullable(DateTime64))` and `Array(Nullable(DateTime))` (values are `ZonedDateTime`, the array was
  `LocalDateTime[]`), and for `Array(Nullable(IPv6))` holding IPv4-mapped addresses (read as `Inet4Address`). The
  array is now typed by the values that were read. An array of only `NULL` elements gets the same type as one with
  values for `UInt64` (`BigInteger`), `DateTime`/`DateTime64` (`ZonedDateTime`) and `Tuple` (`Object[]`).
  (https://github.com/ClickHouse/clickhouse-java/issues/3283, https://github.com/ClickHouse/clickhouse-java/issues/3287)
